A program that sums up the world news of Wednesday 18 November 2026 in one image: a three-panel editorial illustration of the Xi–Trump greeting in Shenzhen ahead of the three-way talks with Putin, the US strike on Qeshm Island and Iranian drones over the Gulf, and the Kerch Bridge hit again with part of its road span collapsed.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the image to `out/entry.png` (1024×1024 JPEG, 278,182 bytes, deterministic: two runs write identical bytes).
